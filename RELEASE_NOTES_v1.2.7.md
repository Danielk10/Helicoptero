# Notas de Lanzamiento - Helicoptero v1.2.7 🚁

## 📋 Novedades y Correcciones

### 🛡️ Actualización de SDKs de AndroidX (Google Play Console)
- **androidx.activity:activity:** Actualizado a `1.10.1` (corrige la advertencia de SDK desactualizado `1.0.0` requerida por Google Play).
- **androidx.fragment:fragment:** Actualizado a `1.8.6` (corrige la advertencia de SDK desactualizado `1.1.0` requerida por Google Play).
- **Resolución de Dependencias:** Declaración explícita en `android/build.gradle` para sobreescribir las dependencias transitivas heredadas obsoletas de los servicios de Google Play.

### 🚀 Preparación para Producción
- **Incremento de Versión:** Actualizado a `versionCode 16` y `versionName 1.2.7`.
- **Compatibilidad:** Mantiene compatibilidad con `targetSdkVersion 37`, Java 17 y desugaring de Java 8+.
